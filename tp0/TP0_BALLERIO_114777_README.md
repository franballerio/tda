# TP0 — Cuartetos de Números Primos

TP 0 — TDA (2C 2026)

## Descripción

El programa calcula y muestra todos los cuartetos de números primos de la forma `(n, n+2, n+6, n+8)` menores a 1.000.000, por ejemplo `(11, 13, 17, 19)` y `(101, 103, 107, 109)`.

## Requisitos

- Python **3.10 o superior** (utiliza `math.isqrt`).
- Sin dependencias externas.

## Cómo ejecutar

En el directorio donde se encuentre el archivo `TP0_BALLERIO_114777.py`, ejecutar:
```bash
python3 TP0_BALLERIO_114777.py
```

## Salida

- La primera línea es el cuarteto fijo `2 3 5 7`.
- Cada línea siguiente contiene un cuarteto de primos: 4 números separados por espacios, uno por cuarteto, en orden ascendente.
- La última línea es el tiempo total de ejecución del programa, expresado en segundos.
